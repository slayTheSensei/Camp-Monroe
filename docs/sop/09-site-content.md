The **Content** section at `/admin/content` lets you edit the copy displayed on the public website — no developer needed.

## What's editable

Currently grouped by section:

- **Nav** — link labels, CTA button label, logo URLs
- **Hero** — headline, subhead, background image
- **Mission** — copy and any supporting media
- **Story** — the longer narrative block
- **Trips intro** — the section that leads into the experiences grid
- **Waitlist** — the email-capture section copy
- **Footer** — contact email, social links, legal copy

## Editing

1. Go to `/admin/content`
2. Find the section you want
3. Edit the values inline
4. Click **Save** for that section

Changes appear on the public site within seconds. Hard-refresh if you don't see them immediately (⌘⇧R / Ctrl+F5).

## Tips

- **Keep headline copy short** — 5-8 words max for hero and section headers
- **Lead with value, not features** — "A quiet lakefront for the work that matters" vs. "Historic 1893 property with lake access"
- **The contact email in the footer is the email prospects will reach you at** — make sure it's the right one, especially if you've rebranded

## What's not editable here

Things NOT controlled by Site Content:

- Navigation links that go to specific admin routes or public pages (those are in code — ask Kyle if a new link is needed)
- The retreat/buyout inquiry pages (`/host-a-retreat`, `/stay-at-camp`) — those have their own hero copy in code
- The calendar component
- Legal pages (terms, privacy — if we add them later, they'd live here or in their own table)

If you want to edit something and can't find it in Content, ask Kyle — it can probably be added to the Content system.
